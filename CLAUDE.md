# CLAUDE.md

This repo is the website for **Fairview Baptist Temple** in Clay, West Virginia
(https://fairviewbaptisttemple.com). A plain static HTML/CSS/JS site, no build step.

Start with **[AGENTS.md](AGENTS.md)**: deploy workflow, ground rules (clean URLs, no em dashes
in copy, KJV, the teal/navy/aqua design tokens (from the church's real logo), Fraunces + Source Sans 3), the Studio CMS layer
(`window.FBT`, `FBT_SCHEMA`, `FBT_FEEDS`, bucket `fbt-media`), and key features.

**[README.md](README.md)** has the page list, the church facts already wired in, and the
remaining `[bracket]` placeholders. Setup guides: [CMS-SETUP.md](CMS-SETUP.md) and
[LIVESTREAM-SETUP.md](LIVESTREAM-SETUP.md).
